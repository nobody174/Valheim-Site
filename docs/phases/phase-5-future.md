# Phase 5 - Future expansion

An open backlog, not a schedule. The owner picks items from `docs/FEATURES.md` section B
(ranks 13 to 25) after using the site for a while.

## Candidates

- ~~Personal notes per item and profile~~ done: a "My note" box on every item page, saved in the profile (max 2000 characters) and included in the backup file
- ~~Read the Valheim character file~~ done: the "My character" page reads a `.fch` file in the browser (nothing is uploaded), shows gear, skills, stations, zones, bosses and kills, and ticks found and crafted items in the matching profile
- Weight and inventory planner (carry weight, ship cargo)
- Farming, cooking and taming reference
- Skills reference
- Console / dev-commands cheat sheet
- Random events, raids and weather
- Update log between game versions (diff of `/data` by `gameVersion`)
- Dungeon and point-of-interest guide
- Printable / shareable checklist and shopping list
- Optional: community-contributed corrections via GitHub issues template

## Rules

- Same working agreement as other phases: plan first, one feature per session, validate, update ROADMAP.
- New features that need new data go through the same source register and `verified` rules.
- If something needs a backend (shared lists, accounts), stop and discuss it in chat first;
  the project is deliberately static and free.
