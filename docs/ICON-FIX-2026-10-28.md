# App icon fix (2026-10-28)

Branch: `fix-app-icons`. Already implemented, built and tested. Review and merge into `main`.
Nothing else needs to be done for this fix.

## Problem

Adding the site to the iPhone home screen showed a white square with half a rune on the
right edge. Cause: `public/icon-192.png` was a corrupt render (white, with only a sliver of
the ring at the right edge), and `index.html` used it as the `apple-touch-icon`.
`icon-512.png` and `icon.svg` were fine.

## Changes

- Regenerated all PNG icons from `public/icon.svg` (opaque `#111111` background, no alpha):
  - `apple-touch-icon.png` (180x180, new, used by iOS)
  - `icon-192.png`, `icon-512.png` (replaced)
  - `icon-maskable-512.png` (new, artwork inside the central 80% safe zone)
  - `favicon-32.png` (new, browser tab fallback next to the SVG favicon)
- `index.html`: new `apple-touch-icon` link, PNG favicon link, and the
  `apple-mobile-web-app-*` meta tags.
- `vite.config.ts`: manifest `maskable` entry now points to `icon-maskable-512.png`, and the
  new files are listed in `includeAssets` so the service worker precaches them.

## Verification

- `npm run lint`, `npm run test` (198 passed) and `npm run build` pass.
- Built `dist/index.html` links resolve under the `/Valheim-Site/` base path.

## After merging and deploying

iOS caches home-screen icons hard. On the iPhone: delete the existing home-screen app, then
re-add it from Safari (Share, Add to Home Screen). Hard-refresh desktop browsers for the
tab favicon.

## If the source art changes

Edit `public/icon.svg`, then regenerate the PNGs at the sizes above (flatten onto `#111111`,
no transparency).
